      Planning implication

      On the final holdout, adding promotions to t0-beta reduced RMSLE from 0.46917 to 0.41312 and increased MAE from 70.82 to 71.45 units.

      If the 16-day schedule is available at forecast time, compare promotion-aware forecasts with a low-cost weekday baseline. Track unit errors and availability alongside RMSLE before using forecasts to order inventory.

      Follow-up with pooled gradient boosting

      Histogram gradient boosting (HGB) learns across all stores and families using calendar features and sales history available at each origin. The optional promotion input uses the forecast-date schedule.
